# VT + BNDW 蒙地卡羅 10,000 組資產路徑模擬器

這是一個 100% 純前端 JavaScript/HTML5 實現的蒙地卡羅投資組合模擬器。不需要安裝任何 Node.js、npm 或後端伺服器，直接用瀏覽器打開即可執行！

## 🚀 使用方式

直接使用任何網頁瀏覽器（Google Chrome, Microsoft Edge, Apple Safari, Mozilla Firefox 等）**點擊打開 [`index.html`](file:///home/pancala/Documents/monte-carlo/index.html)** 即可立刻使用。

## 📊 主要功能

- **10,000 組路徑蒙地卡羅模擬**：採用幾何布朗運動 (Geometric Brownian Motion, GBM) 與 Box-Muller 隨機數轉換。
- **靈活參數輸入**：
  - 初始資產、每年預期投入金額、薪資年增率
  - 投入頻率（定期定額每月 / 每年單筆）
  - 投資年數（5 ～ 40 年）
  - VT (全球股票) 與 BNDW (全球債券) 資產配置比例滑桿 (包含 80/20, 60/40, 100/0, 40/60 快捷鍵)
  - 自由調整 VT / BNDW 的預期報酬率、波動度（標準差）、相關係數及 ETF 費用率
  - 預期通膨率折現（顯示實質購買力）
  - 目標退休資產金額與達標成功率計算
- **四大視覺化圖表與數據面板**：
  - 關鍵指標 KPI 摘要卡片（中位數最終資產、樂觀 P90、悲觀 P10、達標成功機率、預期年化 CAGR %）
  - 蒙地卡羅資產變化路徑圖 (Fan Chart，含 25%-75% 與 10%-90% 分位區間，支援 50 條隨機路徑與對數座標軸切換)
  - 最終資產分佈直方圖 (Histogram)
  - 每年最樂觀 vs 最悲觀分位趨勢圖
  - 每年詳細統計表格 (P1 至 P99)，支援一鍵匯出 CSV 報表
