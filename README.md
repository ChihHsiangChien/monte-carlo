# 蒙地卡羅資產模擬器 (Monte Carlo Portfolio Simulator)

這是一個 100% 純前端 JavaScript/HTML5 實現的蒙地卡羅投資組合模擬器。不需要安裝任何 Node.js、npm 或後端伺服器，直接用瀏覽器打開即可執行！

🔗 **線上展示網址 (GitHub Pages)**: [https://chihhsiangchien.github.io/monte-carlo/](https://chihhsiangchien.github.io/monte-carlo/)

---

## 使用方式

1. **線上使用**：直接點擊上方 GitHub Pages 連結即可線上使用。
2. **本機使用**：用任何網頁瀏覽器直接點擊打開專案中的 [`index.html`](index.html) 即可立刻離線執行。

---

## 主要功能

- **10,000 組路徑蒙地卡羅模擬**：採用幾何布朗運動 (Geometric Brownian Motion, GBM) 與 Box-Muller 隨機數轉換。
- **極值路徑自動辨識**：精準納入各年度最高資產路徑 (翠綠色實線) 與各年度最低資產路徑 (紅色虛線)。
- **靈活參數輸入**：
  - 初始資產、每年定期投入金額
  - 投入頻率（定期定額 / 單筆投入）
  - 投資年數（1 ～ 40 年）
  - VT (全球股票) 與 BNDW (全球債券) 資產配置比例滑桿
  - 自由調整 VT / BNDW 的預期報酬率、年化波動度（標準差）與股債相關係數
  - 預期通膨率折現開關（顯示實質購買力）
  - 目標資產金額與達標成功率計算
- **視覺化圖表與數據面板**：
  - 關鍵指標 KPI 摘要卡片（中位數最終資產、樂觀 P90、悲觀 P10、達標成功機率、預期年化 CAGR %）
  - 蒙地卡羅資產變化路徑圖 (Fan Chart，含 25%-75% 與 10%-90% 分位區間、左右對稱雙 Y 軸、預設對數座標軸切換、25~500 條路徑密度選擇)
  - 懸停高亮整條路徑，並即時顯示該隨機軌跡的最終資產數字
  - 最終資產分佈直方圖 (Histogram)
  - 每年最樂觀 vs 最悲觀分位趨勢圖
  - 每年詳細統計表格 (P1 至 P99)，支援一鍵匯出 CSV 報表
